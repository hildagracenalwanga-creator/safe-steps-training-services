# Safe Steps Training Services

A web platform for Safe Steps Training Services featuring brand alignment, dropdown navigation, custom rounded component design, client-side state management, and Express backend API integration.

## Color Scheme
- **Primary Deep Blue**: `#23227c`
- **Yellow Gold Accent**: `#fbbf24`
- **White**: `#ffffff`
- **Black**: `#111111`

## Key Enhancements
1. **Logo & Tagline Integration**: Matches branding with a centered circular logo and subtitle tagline: *Protecting Children Empowering Families Strengthening Communities*.
2. **Rounded Aesthetics**: High border radius across all cards, inputs, and pill buttons.
3. **Dropdown Navigation & Slide Cart**: Animated header dropdown menu and smooth overlay shopping drawer.
4. **Backend Server**: Single Node.js server handling contact submissions and store orders.
